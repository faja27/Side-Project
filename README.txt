# Side-Projects - Repository

Kumpulan proyek sampingan yang berfokus pada eksplorasi teknologi baru, otomatisasi perdagangan (trading automation), dan pengembangan aplikasi web eksperimental. Repositori ini berfungsi sebagai taman bermain (playground) untuk menguji algoritma dan alat bantu teknis di luar riset akademik utama.

---

## 📂 Project List

### 1. Forex & Crypto Automation (Trading Bot)
Eksplorasi algoritma perdagangan otomatis untuk pasar finansial (XAU/USD & Crypto).
* **RSI Scalping Bot (MT5):** Expert Advisor yang menggunakan strategi Relative Strength Index untuk scalping pada timeframe rendah (M1). Dilengkapi dengan fitur Max Daily Loss dan Session Trading.
* **Crypto Private Bot:** Skrip otomatisasi untuk memantau wallet, market alerts, dan eksekusi transaksi pada aset kripto secara privat.
* **Status:** Active / Testing
* **Tech Stack:** MQL5, Python.

### 2. Market Analyst Terminal
Pengembangan antarmuka web untuk pemantauan pasar secara real-time.
* **Market Analyst Terminal v2:** Terminal berbasis web untuk visualisasi data pasar dan alat bantu analisis teknis bagi trader.
* **Status:** Development
* **Tech Stack:** HTML5, JavaScript, CSS (Tailwind/Bootstrap).

### 3. Kuro Web Project (Solana Ecosystem)
Proyek pengembangan landing page komunitas yang berfokus pada ekosistem Solana, menggunakan animasi GSAP untuk pengalaman pengguna yang dinamis.
* **Status:** Maintenance
* **Tech Stack:** HTML, CSS, JavaScript, GSAP.
